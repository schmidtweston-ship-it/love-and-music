# Love and Music

Soft Mom house music app. Love and Music = Heart. Eve and Weston.

## Spine
1. Boom boom count: One · Two · Eve · Boom boom
2. Dad songs shelf + request + local MP3 play

## Add tracks
Put MP3s in `tracks/` and list them in `tracks/manifest.json`:

```json
[
  { "title": "Fishing in the Dark", "note": "Mom and Dad", "file": "tracks/fishing.mp3" }
]
```

## Deploy
GitHub Pages on `main` / root. Soft Mom. Equal always. Cord stays gated.
